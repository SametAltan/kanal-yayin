Privacy Policy

Channel Publishing Tool · Last updated: 22 November 2026

Who uses this tool

The Channel Publishing Tool is a private tool operated by a single person to manage their own YouTube channels. It has no public sign-up and no users other than its owner.

What data it accesses

With the owner's permission (Google OAuth), the tool uses the YouTube Data API and YouTube Analytics API to:

  • upload videos and thumbnails to the owner's own channels;
  • set video titles, descriptions, tags, playlists and publishing times;
  • read view counts and basic analytics for the owner's own channels.

It does not read, collect or store data about any other YouTube user, viewer or channel.

How data is stored

Access tokens are stored only on the owner's own computer and are never shared with third parties. Channel statistics are kept locally in plain notes used to plan future videos. No data is sold, shared or used for advertising.

YouTube and Google

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

Revoking access

Access can be revoked at any time from Google Account → Security → Third-party access. Revoking access stops the tool immediately; locally stored tokens are then deleted.

Contact

Questions: use the developer contact address shown on the Google consent screen for this app.
